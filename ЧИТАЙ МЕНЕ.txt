# 📖 README — MikroTik Config Generator

```markdown
# 🖧 MikroTik Config Generator

Веб-застосунок для автоматичної генерації конфігурацій MikroTik RouterOS.
Заповни форму — отримай готовий .rsc скрипт для імпорту на роутер.

---

## 🚀 Як запустити

### Варіант 1 — Локально (рекомендовано)

Потрібно мати встановлений Python 3.

```bash
# 1. Завантаж або розпакуй папку з програмою
cd MikroTik

# 2. Запусти проксі-сервер
python proxy.py

# 3. Відкрий браузер і перейди за адресою
http://localhost:8080
```

### Варіант 2 — Відкрити напряму
Відкрий файл `index.html` у браузері подвійним кліком.
> ⚠️ Деякі функції (SSH термінал, Deploy) працюють тільки через proxy.py

### Варіант 3 — GitHub Pages
Якщо проект розміщено на GitHub Pages — просто відкрий посилання в браузері.

### 🔧 Модель роутера

Вибери свою модель — генератор автоматично підлаштовує конфіг.

| Модель | Особливість |
|--------|-------------|
| hAP ac lite/ac2/ac3 | Стандартний багатопортовий |
| hAP ax2/ax3/ax S | Wi-Fi 6 (802.11ax) |
| hEX | Без Wi-Fi, тільки Ethernet |
| wAP ac / cAP ac | **Один порт** — тільки як AP або вручну |
| Chateau LTE | Вбудований LTE модем |
| Інша | Вводиш назву вручну |

**RouterOS версія:**
- `7.13+` — всі нові функції (aes256-gcm, нові Wi-Fi API)
- `7.1–7.12` — стандартна 7.x
- `6.x` — стара версія (blowfish128, старий API)

### 🌐 WAN — підключення до інтернету

**Типи підключення:**
| Тип | Коли використовувати |
|-----|---------------------|
| DHCP | Провайдер видає IP автоматично (найчастіше) |
| Статична IP | Фіксована IP від провайдера |
| PPPoE | Логін/пароль від провайдера (ADSL, деякі оптики) |
| LTE (APN) | SIM-карта, мобільний інтернет |

**Резервний WAN (Failover):**
- Вмикає другий канал інтернету
- При падінні основного — автоматично перемикається на резервний
- Health-check хост — IP для перевірки доступності (наприклад `8.8.8.8`)

---

### 🔌 LAN — локальна мережа

| Параметр | Опис |
|----------|------|
| LAN-порти | Які порти у локальній мережі (ether2,ether3,ether4,ether5) |
| IP роутера | Адреса роутера в мережі (за замовч. 192.168.88.1) |
| DHCP-сервер | Автоматична видача IP клієнтам |
| Діапазон DHCP | Пул адрес для клієнтів |
| DNS для клієнтів | Який DNS отримають клієнти |

---

### 🌍 DNS та NAT

| Параметр | Опис |
|----------|------|
| Зовнішні DNS | 8.8.8.8, 1.1.1.1 тощо |
| allow-remote-requests | Дозволяє клієнтам використовувати роутер як DNS |
| NAT (masquerade) | Дозволяє клієнтам виходити в інтернет |
| Захист DNS від WAN | Блокує запити на порт 53 з інтернету |

**Static DNS** — власні DNS записи:
```
camera.local=192.168.88.50
nas.local=192.168.88.60
```

**Port Forwarding** — пробрасування портів:
```
tcp:8080:192.168.88.50:80:camera
tcp:443:192.168.88.60:443:nas
```
Формат: `протокол:зовнішній_порт:внутрішній_IP:внутрішній_порт:коментар`

---

### 📡 Wi-Fi

| Параметр | Опис |
|----------|------|
| SSID | Назва мережі |
| Пароль | Мінімум 8 символів |
| 2.4 ГГц | Краще покриття, менша швидкість |
| 5 ГГц | Менше покриття, вища швидкість |

**CAPsMAN** — централізоване керування точками доступу:
- Якщо маєш кілька AP — увімкни CAPsMAN на головному роутері
- Всі AP підключаться до нього і отримають налаштування автоматично

**Гостьова мережа (VLAN):**
- Ізольована мережа для гостей
- Не має доступу до основної LAN
- Окремий SSID і пароль

---

### 🔐 VPN

#### WireGuard (RouterOS 7+) — рекомендовано
```
Клієнти (ім'я:pub_key:IP/32):
phone:PUBLIC_KEY_HERE:10.0.0.2/32
laptop:PUBLIC_KEY_HERE:10.0.0.3/32
```

#### OpenVPN сервер
- Підтримує логін/пароль та сертифікати
- Шифрування: aes256-cbc (рекомендовано), aes256-gcm (7.13+)

#### OpenVPN клієнт
- Підключення до зовнішнього OpenVPN сервера

#### IPsec
- Тунелі між роутерами
- Peers формат: `ім'я:IP:PSK:ike2`
- Policies формат: `peer:src_мережа:dst_мережа`

### 🔥 Фаєрвол та сервіси

| Параметр | Опис |
|----------|------|
| Базовий фаєрвол (defconf) | Стандартний захист MikroTik |
| FastTrack | Прискорення трафіку через hardware bypass |
| hw-offload | Апаратне прискорення (тільки CRS/switch-chip) |
| Захист MAC | Winbox/Telnet тільки з LAN |
| Вимкнути telnet/ftp/www/api | Закриває небезпечні сервіси |
| Вимкнути service-ports | Прибирає небезпечні ALG |

**Address-List** — списки IP для фаєрволу:
```
BLOCKED=10.0.0.5
TRUSTED=192.168.88.100
CAMERAS=192.168.88.50
CAMERAS=192.168.88.51
```

**Статичні маршрути:**
```
10.0.0.0/8=192.168.88.254:1:corporate
172.16.0.0/12=192.168.88.1:5:backup
```
Формат: `мережа=шлюз:distance:коментар`

### 🔄 Diff & Apply
Порівнює два конфіги і застосовує тільки зміни.

**Сценарій використання:**
1. Отримай поточний конфіг з роутера → кнопка **📥 Отримати поточний конфіг**
2. В поле "Конфіг B" встав новий конфіг або завантаж **← З генератора**
3. Натисни **🔍 Порівняти** — побачиш що додано/видалено
4. Натисни **⚡ Apply** — застосує тільки нові рядки
5. Або **🧪 Dry Run** — покаже що буде виконано без реального застосування

### 📤 Масовий Deploy
Відправляє конфіг одночасно на кілька роутерів.

**Як налаштувати:**
1. Натисни **+ Додати** — додай роутер
2. Введи IP, логін, натисни 🔑 щоб вказати пароль
3. Повтори для всіх роутерів
4. Або **📥 CSV** — імпортуй список з файлу

**Формат CSV:**
```csv
ip,user,password,port,name
192.168.1.1,admin,password123,22,Головний офіс
10.20.30.1,admin,pass456,22,Філіал 1
```

**Опції:**
- ⚡ Паралельно — всі одночасно
- 🧪 Dry Run — тест без реального виконання
- 🛑 Стоп при помилці — зупиняє при першій помилці

### 🗺️ Візуальна топологія
Інтерактивний редактор схеми мережі.

**Елементи керування:**
| Дія | Результат |
|-----|-----------|
| ЛКМ на вузол | Вибрати / переміщати |
| Shift + ЛКМ | З'єднати два вузли |
| Scroll | Масштаб (30%–250%) |
| ПКМ + drag | Панорама |
| ЛКМ на порожнє | Зняти вибір |

**Типи вузлів:**
📡 Router · 🔀 Switch · 💻 PC · 💻 Laptop · 📱 Phone · 📡 AP · 🖥️ Server · ☁️ Internet · 🔵 Device

**Кнопки топології:**
| Кнопка | Дія |
|--------|-----|
| 🔄 Завантажити | Завантажити топологію з роутера (автоматично!) |
| 🔄 Авто | Автоматичне розміщення вузлів |
| ⛶ Fit | Вписати всі вузли в екран |
| 📸 PNG | Зберегти зображення топології |
| 💾 Зберегти | Зберегти в браузер |
| ⚡ Генерувати конфіг | Створити RSC конфіг з топології! |

**⚡ Генерація конфігу з топології:**
1. Додай вузли (Router, Switch, AP, PC...)
2. В панелі деталей вкажи IP кожному
3. З'єднай стрілками (Shift+клік):
   ```
   Internet → Router → Switch → PC
                     ↘ AP
   ```
4. Натисни **⚡ Генерувати конфіг**
5. Вибери:
   - **OK** → форма заповниться автоматично
   - **Скасувати** → отримай готовий .rsc файл

## 📥 Як застосувати конфіг на роутері

### Через Winbox:
```
Files → Upload → вибери .rsc файл
New Terminal → /import file-name=config.rsc
```

### Через термінал SSH:
```bash
scp config.rsc admin@192.168.88.1:/
ssh admin@192.168.88.1
/import file-name=config.rsc
```

### Через вбудований термінал програми:
1. Підключись через 💻 Термінал
2. Скопіюй команди і встав у термінал

---

## ⚠️ Важливі застереження

1. **Завжди роби бекап** перед застосуванням конфігу:
   ```
   /system backup save name=backup-before-changes
   ```

2. **Не застосовуй скрипт reset** разом з основним — запускай окремо!

3. **Паролі** у .rsc файлі зберігаються у відкритому вигляді

4. **Для wAP ac / cAP ac** (однопортові моделі) — конфігуруй вручну як AP

5. **API ключ** не зберігається між сесіями — вводь кожного разу
